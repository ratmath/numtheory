Reference

Everything in the library

Every export of @ratmath/numtheory. Whole-number arguments may be numbers, BigInts, digit strings or Core Rationals with denominator 1; a JavaScript number that is not whole is refused. Results are BigInts, except symbols (−1, 0, 1) and valuations, which are plain numbers. Refusals throw a NumberTheoryError whose code says why.

Primes and certificates

ExportWhat it does
primes(limit)The primes up to the limit (at most 10⁷), by the sieve of Eratosthenes.
primePi(x), nthPrime(k)\(\pi(x)\) exactly, up to 10¹² (a sieve below 10⁷, Meissel's formula above); the k-th prime.
isPrime(n)Proven below 2⁶⁴ (Baillie–PSW); above, by a certificate, or throws "unproven".
isProbablePrime(n)Baillie–PSW alone: fast, not a proof above 2⁶⁴.
nextPrime(n), prevPrime(n), primesBetween(a, b)Neighbouring primes; the primes in a window (segmented sieve, b < 2⁶⁴).
provePrime(n, { budget, elliptic, maxDiscriminant, maxClassNumber }){ prime, proven, certificate | factor | witness | reason }: a Pocklington, Brillhart–Lehmer–Selfridge or elliptic curve certificate, a factor or a Miller–Rabin witness, or the reason none was found. elliptic: false uses n − 1 only.
classPolynomial(D)The Hilbert class polynomial \(H_D\) of a negative discriminant, coefficients constant term first; its degree is the class number.
verifyCertificate(cert)The independent checker: { valid: true } or { valid: false, reason }. Shares no code with the search.
verifyComposite(n, { factor, witness })Checks a proof of compositeness.
millerRabinWitness(n, a)True when a proves n composite by the strong test.

ecmCurve(n, sigma, { B1, B2 })One Suyama curve, as a report.
formatFactors(fs)"2^3 · 3 · 5^2".
trialDivide(n, limit){ found: Map(prime → exponent), rest }.
pollardRho(n, { steps, seed })A nontrivial factor by Brent's rho, or null.
pollardPm1(n, bound)A factor p with p − 1 smooth to the bound, or null.
factorInteger, modPow, modInverse, multiplicativeOrder, primitiveRoot, discreteLogMod, sqrtMod, lll, recognizeRe-exported from @ratmath/algebraic, which keeps the modular kernel for its finite fields.
