Continued fractions

Continued fractions

Every real number is a₀ + 1/(a₁ + 1/(a₂ + …)) with whole numbers aₖ, written [a₀; a₁, a₂, …]. Rationals stop, quadratic irrationals repeat forever, and the cut-off fractions are the best rational approximations there are.

These functions moved here from @ratmath/algebraic, which still provides the algebraic numbers they work on.

Exact terms for any algebraic number

For an algebraic \(x\), the root of \(p\) in an interval, the next term is \(t = \lfloor x \rfloor\): shrink the interval until it lies between two integers. Then \(x = t + 1/y\), and \(y\) is a root of

\[ q(y) = y^d\, p(t + 1/y), \]

\(p\) shifted by \(t\) with its coefficients reversed, in the interval mapped by \(y = 1/(x - t)\). No digit of \(x\) is approximated, so every term is right. \(\sqrt[3]{2} = [1; 3, 1, 5, 1, 1, 4, 1, \dots]\) shows no pattern, and nobody knows whether its terms are bounded.

import { continuedFraction, convergents, periodicContinuedFraction, fromContinuedFraction, pell, fundamentalUnit } from "@ratmath/numtheory";
import { nthRoot, sqrt, fromRational } from "@ratmath/algebraic";

continuedFraction(nthRoot(fromRational(2), 3), 8);   // [1n, 3n, 1n, 5n, 1n, 1n, 4n, 1n]
continuedFraction("103993/33102");                   // [3n, 7n, 15n, 1n, 292n]: a convergent of π
convergents([1, 2, 2, 2]).map(String);               // ["1", "3/2", "7/5", "17/12"]

The convergents \(p_k/q_k\) satisfy \(p_k = a_k p_{k-1} + p_{k-2}\), \(q_k = a_k q_{k-1} + q_{k-2}\), and \(|x - p_k/q_k| < 1/q_k^2\). Each is closer to \(x\) than any fraction with a smaller denominator. A large next term means an unusually good convergent: \(\pi\)'s 355/113 comes right before the term 292.

Quadratic irrationals repeat

Lagrange: the expansion is eventually periodic exactly when \(x\) is a quadratic irrational. Written as \(x = (P + \sqrt D)/Q\) with \(Q \mid D - P^2\), each step is

\[ a = \left\lfloor \frac{P + \sqrt D}{Q} \right\rfloor, \qquad P' = aQ - P, \qquad Q' = \frac{D - P'^2}{Q}, \]

all in integers. Only finitely many pairs \((P, Q)\) occur, so one repeats, and the period is read off exactly.

periodicContinuedFraction(sqrt(fromRational(7)));   // { preperiod: [2n], period: [1n, 1n, 1n, 4n] }
fromContinuedFraction([1], [2]);                    // √2 exactly: [1; 2, 2, 2, …]

Pell's equation and units

\(x^2 - Dy^2 = 1\) (\(D\) not a square) always has solutions, and the smallest comes from the period of \(\sqrt D\): if the period has length \(L\), the convergent just before the end of the first period gives \(p^2 - Dq^2 = (-1)^L\). For odd \(L\) that solves the \(-1\) equation, and a second period solves the \(+1\) equation. \(D = 61\) is Fermat's challenge to the English mathematicians. The same computation gives the fundamental unit \(\varepsilon > 1\) of the integers of \(\mathbb Q(\sqrt d)\): every unit is \(\pm\varepsilon^n\) (Dirichlet). The Pell page solves \(x^2 - Dy^2 = N\) for any \(N\).

pell(61);              // { x: 1766319049n, y: 226153980n, negative: { x: 29718n, y: 3805n } }
fundamentalUnit(94);   // { unit: 2143295 + 221064√94, norm: 1 }
