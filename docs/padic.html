p-adic numbers

Measure a number by how often p divides it, and the integers acquire a new completion: numbers with infinitely many digits to the left. Here a p-adic number is a rule that produces as many digits as you ask for, exactly.

Valuation and the p-adic size

For a rational x≠0x \neq 0x=0, vp(x)v_p(x)vp​(x) is the exponent of ppp in xxx and ∣x∣p=p−vp(x)|x|_p = p^{-v_p(x)}∣x∣p​=p−vp​(x). So ∣50/27∣5=1/25|50/27|_5 = 1/25∣50/27∣5​=1/25 and ∣50/27∣3=27|50/27|_3 = 27∣50/27∣3​=27: being divisible by ppp makes a number small. This size satisfies the strong triangle inequality ∣x+y∣p≤max⁡(∣x∣p,∣y∣p)|x + y|_p \le \max(|x|_p, |y|_p)∣x+y∣p​≤max(∣x∣p​,∣y∣p​), and with the ordinary size it gives the product formula ∣x∣∏p∣x∣p=1|x| \prod_p |x|_p = 1∣x∣∏p​∣x∣p​=1.

Infinitely many digits to the left

Completing Q\mathbb QQ with ∣⋅∣p|\cdot|_p∣⋅∣p​ gives Qp\mathbb Q_pQp​, whose elements are ∑i≥vdipi\sum_{i \ge v} d_i p^i∑i≥v​di​pi with digits 0≤di<p0 \le d_i < p0≤di​<p, written right to left. In Z5\mathbb Z_5Z5​, …4444=−1\dots 4444 = -1…4444=−1: add 1 and every digit carries. A rational's expansion is eventually periodic, and conversely.

padic("1/10", 5n).toString();  // "…2222222222222222222.3"

Lazy and exact

A Padic is a rule: given NNN, it returns a rational rrr with vp(x−r)≥Nv_p(x - r) \ge Nvp​(x−r)≥N. Rationals are exact. A sum asks its parts for precision NNN; a product asks each for NNN minus the other's valuation; a quotient first finds the divisor's valuation. Nothing is fixed in advance, so asking for more digits reruns the whole computation to that depth, and results are cached. What cannot be decided by digits is reported: the valuation of a number that may be zero is searched for, and the search gives up with the code "unknown-valuation" rather than claiming a zero.

Square roots and Hensel

For odd ppp, a unit uuu is a square in Zp\mathbb Z_pZp​ exactly when it is a square mod ppp; for p=2p = 2p=2, when u≡1(mod8)u \equiv 1 \pmod 8u≡1(mod8). Then Newton's iteration from a root mod ppp converges ppp-adically, doubling the correct digits each step. henselRoot does the same for any polynomial, given a start r0r_0r0​ with v(f(r0))>2v(f′(r0))v(f(r_0)) > 2v(f'(r_0))v(f(r0​))>2v(f′(r0​)).

i.toString();                   // "…40423140223032431212": a square root of −1 in Z₅
i.mul(i).toString();            // "…44444444444444444444"
padic(-7, 2n).sqrt();           // exists: −7 ≡ 1 (mod 8)
