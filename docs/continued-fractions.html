Continued fractions

Every real number is a₀ + 1/(a₁ + 1/(a₂ + …)) with whole numbers aₖ, written [a₀; a₁, a₂, …]. Rationals stop, quadratic irrationals repeat forever, and the cut-off fractions are the best rational approximations there are.

These functions moved here from @ratmath/algebraic, which still provides the algebraic numbers they work on.

Exact terms for any algebraic number

For an algebraic xxx, the root of ppp in an interval, the next term is t=⌊x⌋t = \lfloor x \rfloort=⌊x⌋: shrink the interval until it lies between two integers. Then x=t+1/yx = t + 1/yx=t+1/y, and yyy is a root of

q(y)=yd p(t+1/y), q(y) = y^d\, p(t + 1/y), q(y)=ydp(t+1/y),

ppp shifted by ttt with its coefficients reversed, in the interval mapped by y=1/(x−t)y = 1/(x - t)y=1/(x−t). No digit of xxx is approximated, so every term is right. 23=[1;3,1,5,1,1,4,1,… ]\sqrt[3]{2} = [1; 3, 1, 5, 1, 1, 4, 1, \dots]32​=[1;3,1,5,1,1,4,1,…] shows no pattern, and nobody knows whether its terms are bounded.

import { continuedFraction, convergents, periodicContinuedFraction, fromContinuedFraction, pell, fundamentalUnit } from "@ratmath/numtheory";
import { nthRoot, sqrt, fromRational } from "@ratmath/algebraic";

continuedFraction(nthRoot(fromRational(2), 3), 8);   // [1n, 3n, 1n, 5n, 1n, 1n, 4n, 1n]
continuedFraction("103993/33102");                   // [3n, 7n, 15n, 1n, 292n]: a convergent of π
convergents([1, 2, 2, 2]).map(String);               // ["1", "3/2", "7/5", "17/12"]

Quadratic irrationals repeat

Lagrange: the expansion is eventually periodic exactly when xxx is a quadratic irrational. Written as x=(P+D)/Qx = (P + \sqrt D)/Qx=(P+D​)/Q with Q∣D−P2Q \mid D - P^2Q∣D−P2, each step is

a=⌊P+DQ⌋,P′=aQ−P,Q′=D−P′2Q, a = \left\lfloor \frac{P + \sqrt D}{Q} \right\rfloor, \qquad P' = aQ - P, \qquad Q' = \frac{D - P'^2}{Q}, a=⌊QP+D​​⌋,P′=aQ−P,Q′=QD−P′2​,

all in integers. Only finitely many pairs (P,Q)(P, Q)(P,Q) occur, so one repeats, and the period is read off exactly.

periodicContinuedFraction(sqrt(fromRational(7)));   // { preperiod: [2n], period: [1n, 1n, 1n, 4n] }
fromContinuedFraction([1], [2]);                    // √2 exactly: [1; 2, 2, 2, …]

Pell's equation and units

x2−Dy2=1x^2 - Dy^2 = 1x2−Dy2=1 (DDD not a square) always has solutions, and the smallest comes from the period of D\sqrt DD​: if the period has length LLL, the convergent just before the end of the first period gives p2−Dq2=(−1)Lp^2 - Dq^2 = (-1)^Lp2−Dq2=(−1)L. For odd LLL that solves the −1-1−1 equation, and a second period solves the +1+1+1 equation. D=61D = 61D=61 is Fermat's challenge to the English mathematicians. The same computation gives the fundamental unit ε>1\varepsilon > 1ε>1 of the integers of Q(d)\mathbb Q(\sqrt d)Q(d​): every unit is ±εn\pm\varepsilon^n±εn (Dirichlet). The Pell page solves x2−Dy2=Nx^2 - Dy^2 = Nx2−Dy2=N for any NNN.
