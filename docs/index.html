@ratmath/numtheory

Number theory with proofs attached

From a first course to algebraic number theory: primes that come with a certificate, congruences and reciprocity, Diophantine equations, p-adic numbers, elliptic curves, and the arithmetic of number fields.

Planned, not built yet. This site is the frame the package will grow into. The full plan is in the library roadmap, and the RatMath Shelf page lists what exists across all the libraries.

What it will cover

  • Primes with primality certificates, arithmetic functions, congruences, quadratic reciprocity, sums of squares.
  • Continued fractions, Pell's equation and the modular toolkit, re-exported from algebraic.
  • Diophantine equations and binary quadratic forms.
  • p-adic numbers.
  • Elliptic curves, factoring with them, and curve-based primality certificates.
  • Integral bases, discriminants and the factorisation of primes into prime ideals.
  • Class groups and unit groups.
  • π(x), Dirichlet characters, and values of ζ and L-functions.

How the docs will be laid out

Like every library on the Shelf: this overview, an Explore page for trying things without writing code, a Reference listing every function, and one page per topic that explains the usage and the mathematics. Every page ends with a box of code you can edit and run.
