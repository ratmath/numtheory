@ratmath/numtheory

Number theory with proofs attached

From a first course to algebraic number theory: primes that come with a certificate, congruences and reciprocity, Diophantine equations, p-adic numbers, elliptic curves, and the arithmetic of number fields.

What is here

Phases 1 to 4 of the plan: primes with certificates, factoring, arithmetic functions, congruences, reciprocity and sums of squares; linear and Pell equations, continued fractions and binary quadratic forms; p-adic numbers; and elliptic curves over the rationals and over finite fields, with the factoring method and the primality certificates built on them. Algebraic number theory and the analytic side are planned and listed at the bottom of this page.

A first program

import { isPrime, provePrime, verifyCertificate, factor, formatFactors, jacobiSteps, twoSquaresAll, pellSolutions, classGroup, padic, ellipticCurve } from "@ratmath/numtheory";

isPrime(2n ** 61n - 1n);                     // true, proven: Baillie–PSW has no exceptions below 2^64
const r = provePrime(2n ** 127n - 1n);       // a Pocklington certificate, a tree of smaller primes
verifyCertificate(r.certificate);            // { valid: true }, by a checker that shares no code with the search
formatFactors(factor(2n ** 64n + 1n));       // "274177 · 67280421310721"

jacobiSteps(1001, 9907).value;               // -1, with every reciprocity step written out
twoSquaresAll(325);                          // [[18n, 1n], [17n, 6n], [15n, 10n]]
pellSolutions(2, 7).solutions(4);            // [[3n, 1n], [5n, 3n], [13n, 9n], [27n, 19n]]
classGroup(-3299).structure;                 // [3n, 9n]: the class group is C3 × C9
padic(-1, 5n).sqrt().toString(12);           // "…223032431212": i in the 5-adic integers

formatFactors(factor(2n ** 128n + 1n));      // "59649589127497217 · 5704689200685129054721", by the elliptic curve method
isPrime(10n ** 60n + 7n);                    // true: an elliptic curve certificate, checked by the same verifier
ellipticCurve([-43, 166]).torsion().structure;   // [7]: y² = x³ − 43x + 166 has a rational point of order 7

Three ideas

A proof, or a refusal. "Prime" means proven: below 2⁶⁴ by a test known to have no exceptions there, above it by a certificate (from the factors of n − 1, or from an elliptic curve) that an independent verifier checks. When no certificate can be found, isPrime refuses and says why, rather than guessing. A composite comes with a factor or a witness. See Primes and certificates.

Every "no" has a reason. A congruence with no solution names the gcd that blocks it, a number that is not a sum of two squares names the prime, two forms that are not equivalent name their different reduced forms, and an equivalence comes with the matrix that proves it.

Exact at any size, lazily where it must be. Everything is BigInt and Core Rational arithmetic. p-adic numbers have infinitely many digits, so they are rules that compute as many as asked, exactly; what digits alone cannot decide, such as whether a number is exactly zero, is reported as unknown. See p-adic numbers.
