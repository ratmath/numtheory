Factoring

Splitting a number into primes: trial division for the small factors, Pollard's rho for the medium ones, and the p − 1 method when a factor happens to have a smooth neighbour. Every prime in the answer says whether it is proven.

The whole factorisation

import { factor, formatFactors } from "@ratmath/numtheory";

formatFactors(factor(600851475143n));   // "71 · 839 · 1471 · 6857"
formatFactors(factor(2n ** 64n + 1n));  // "274177 · 67280421310721": Landry's 1880 split of F₆
formatFactors(factor(10n ** 20n + 1n)); // "73 · 137 · 1676321 · 5964848081"
factor(2n ** 67n - 1n);
// [{ prime: 193707721n, exponent: 1, proven: true },
//  { prime: 761838257287n, exponent: 1, proven: true }]

factor divides out the primes below 10510^5105, then splits what is left: a probable prime goes into the answer, a perfect square is split into its roots, anything else goes to Pollard's rho, then to p−1p - 1p−1, then to the elliptic curve method. Factors below 2642^{64}264 are proven by Baillie–PSW; a larger one is proven by a certificate, and proven: false says when that could not be found.

Pollard's rho

Iterate x↦x2+c(modn)x \mapsto x^2 + c \pmod nx↦x2+c(modn). Modulo an unknown prime p∣np \mid np∣n the sequence lives in a set of size ppp, so it must repeat, and by the birthday paradox it does so after about p\sqrt{p}p​ steps: its picture is the Greek letter ρ\rhoρ, a tail and a loop. Once xi≡xj(modp)x_i \equiv x_j \pmod pxi​≡xj​(modp), gcd⁡(xi−xj,n)\gcd(x_i - x_j, n)gcd(xi​−xj​,n) is a multiple of ppp. Brent's version finds the loop by comparing against a saved value at powers of two, and multiplies many differences together before taking one gcd. The cost is about p\sqrt pp​ multiplications: a 12-digit factor takes around a million.

pollardPm1(1000000007n * 1000000009n);  // 1000000009n
pollardPm1(2n ** 67n - 1n);             // null: see below

Beyond rho

Rho slows down when the smallest prime factor passes about 12 digits. The seventh Fermat number 2128+12^{128} + 12128+1 is the product of two primes of 17 and 22 digits: rho would need hundreds of millions of steps, and p−1p - 1p−1 fails on it. So after a short run of rho and p−1p - 1p−1, factor goes on to the elliptic curve method, which is to p−1p - 1p−1 what a family of groups is to one group, and which finds that 17-digit factor in a fraction of a second. Factors of up to about 25 digits are within reach; beyond that factor gives up with the reason rather than running for hours.
